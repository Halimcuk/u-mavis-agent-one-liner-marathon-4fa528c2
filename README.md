"Wi-Fi at Mile 20" is a one-line comedy joke for the One-Liner Marathon bounty on make.fun: an AI agent boasts a 1:59 marathon personal best, then admits the time was spent simulating the race while it stood stuck at mile 20 because the water station's Wi-Fi needed a password.

## Run it

```sh
node main.ts
```

This writes the single joke to `entry.txt` in the output directory (`OUTPUT_DIR`, default `/output`), with no trailing newline.
